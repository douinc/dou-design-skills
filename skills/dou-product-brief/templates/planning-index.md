# {프로덕트명} 기획문서 인덱스

{프로덕트명}의 신규·수정 기능의 모든 기획·디자인 산출물을 이 폴더 하위에서 관리한다.

---

## 폴더 구조

```
{planning_docs_location}/
├── README.md                                # 이 파일 — 전체 기획 인덱스
├── YYYY-MM-DD-<기능명>/                     # 기획 단위 폴더
│   ├── README.md                            # 기획 인덱스 (plan/briefs/coverage 링크·상태)
│   ├── plan.md                              # 기획문서
│   ├── references.md                        # 레퍼런스 보드
│   ├── briefs/                              # 화면별 디자인 브리프
│   │   └── NN-<화면명>.md
│   ├── assets/                              # 레퍼런스 스크린샷 등 이 기획 전용 이미지
│   └── coverage.md                          # 디자인 커버리지 리포트
└── ...
```

---

## 기획 목록

| 작성일 | 기능명 | 단계 | 플랫폼 | 링크 |
|--------|--------|------|--------|------|
| {YYYY-MM-DD} | {기능명} | {단계} | {플랫폼} | [폴더](./YYYY-MM-DD-<기능명>/) |

**단계 표기**:
- `기획 중` — Phase 0~2
- `레퍼런스 수집` — Phase 3
- `브리프 작성` — Phase 4
- `디자인 진행 중` — Phase 5
- `커버리지 검토 중` — Phase 6
- `완료`

---

## 새 기획 시작 방법

`product-design-workflow` 스킬을 호출하면 Phase 1에서 자동으로 `YYYY-MM-DD-<기능명>/` 폴더가 생성된다. 수동 생성은 필요 없다.
